# 验证说明

## v1.2.0

验证日期：2026-10-07。42 项基础判断、53 项功能判断、24 项项目操作判断、多聊天协调和并发读写检查通过。

- 手动暂停在额度充足时仍中断活动轮次，必须确认后才记为暂停；手动保持暂停不自动恢复。
- 空闲、无历史轮次、已结束项目及已完成 Goal 可主动登记一次继续。暂停 Goal 保留原身份；目标修改、待处理输入、额度不足或未确认的继续请求不会被强行覆盖或重复提交。
- 继续消息编号在提交前持久保存，确认后不重复启动。取消待续、只读拒绝、自动待续计数、未加载请求持久化，以及停止监控优先于项目请求均有模拟检查。
- 轮询依据实际活动状态；空闲监控记录不再导致已暂停后的低额度快查。
- 隔离只读 GUI 验证相关/全部项目切换及保存、四项右键菜单、失败设置、逐项勾选、额度更新、日志和退出。常规及较小窗口实图检查文字完整；EXE、窗口、托盘使用新图标，包含 16–256 像素尺寸。

真实额度读取为只读验证；项目暂停、开始和自动继续采用模拟服务，未在本轮操作真实项目或消耗卡。未加载项目的 Codex 链接依据本机客户端协议代码及已注册链接处理器，未在测试中自动打开真实历史项目。

## v1.1.1

验证日期：2026-10-07。42 项基础判断、53 项功能判断、多聊天协调和并发读写检查通过。

- 已确认暂停后，即使五小时额度低于 10% 或已恢复，也使用常规间隔；暂停/继续待确认或仍有监控中任务时保留相应加速。

- 界面新增失败次数开关和输入框，开启/关闭与持久化采用隔离只读检查，不操作真实聊天或重置卡。

- 多聊天协调：两个普通任务和一个目标各被暂停一次；另一个被旧版误标结束的额度失败任务重新登记；四个任务各提交一次继续请求；正常完成的历史聊天不重启；解除登记有效。
- 并发文件读取与原子替换：1000 次写入和循环读取，不出现残缺 JSON 或文件独占错误。
- 当前客户端图形只读检查：实时读取两项额度和重置时间，保存并应用查询和阈值设置，逐行取消/开启及刷新后的保留，相关聊天筛选，额度标签/使用比例/进度条 65%→7%→0% 更新，日志筛选导出和正常退出。

- 常规和较小窗口实际截图检查；公开截图使用虚构聊天标题和演示额度，未发布用户聊天截图。

所有暂停、继续和重置卡调用检查使用模拟服务。现场验证只读，不消费实际卡，不改变实际聊天或生产暂停记录。当前客户端真实自动控制及消耗卡尚未在此版本重新端到端执行，不能将模拟结果解释为现场消耗成功。

测试入口：仓库根目录 `test.ps1`；构建入口：`build.ps1`。源码不限制客户端版本号，仍核验实际通信格式及任务身份。未知协议、返回缺失或重复提交结果无法确认时记录异常。
